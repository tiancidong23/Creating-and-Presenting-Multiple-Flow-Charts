# AI Big Sister – Flow Chart Project

## Overview

This project presents the design and analysis of an AI-powered application called **AI Big Sister**, which provides relationship and emotional guidance for women.

The goal of this assignment is to demonstrate understanding of different types of flow charts by applying them to a real-world product concept.

---

## Project Contents

This repository includes the following materials:

* 6 Flow Charts:

  * Basic Flow Chart
  * System Flow Chart
  * Workflow Diagram
  * Data Flow Chart
  * Decision Flow Chart
  * Swimlane Flow Chart

* PDF file containing all diagrams (one chart per page)

* YouTube presentation video:
  👉 https://youtu.be/YWvN2i57i9c

---

## Tools Used

* Lucidchart (for diagram creation)
* ChatGPT (for structure and explanation support)
* YouTube (for video presentation)

---

## Project Description

The diagrams provide multiple perspectives of the project, including:

* User journey and interaction flow
* System architecture and component relationships
* Development workflow from idea to launch
* Data movement and processing
* Decision-making logic within the system
* Team responsibilities based on roles

---

## Notes

Each flow chart highlights a specific aspect of the system. Together, they provide a comprehensive understanding of the product from both technical and organizational perspectives.
